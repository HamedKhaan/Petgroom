# پت‌گروم سالن — کاملاً آفلاین

اپ اندروید برای گرومر. بدون سرور، بدون اینترنت برای کار روزمره.

## امکانات
- مشتریان روی SQLite داخل گوشی
- افزودن دستی
- ورود چندتایی از مخاطبین (مجوز «فقط این بار»)
- موعد گذشته
- کار تمام → نوبت بعدی جلو می‌رود
- ارسال پیامک از سیم‌کارت خود سالن
- قالب پیام محلی

## ساخت APK
محتوای این پوشه را ریشه ریپو کنید → Actions → Build APK

واتساپ و برنامه وب برای گرومر استفاده نمی‌شود.
